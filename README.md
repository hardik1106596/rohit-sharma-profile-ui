# 🏏 Rohit Sharma Profile UI

A complete frontend learning project inspired by a modern Rohit Sharma player profile design.

This repository is specially structured for learning frontend development step by step using:

- HTML
- CSS
- JavaScript

The project is divided into:

1. Basic Version
2. Advanced Version

So learners can first understand the fundamentals and then move toward professional frontend UI development.

# 🧠 Why This Repository?

Most frontend tutorials teach concepts separately.

This repository follows a:

# Learn → Build → Improve

approach.

You first build a simple version and then progressively improve it into a professional frontend project.

This helps learners understand:
- why concepts are used
- where concepts are used
- real frontend structure
- modern frontend practices

instead of only copying code.
